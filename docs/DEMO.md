# 演示脚本 · 5 分钟（Owner: E，卡 E7）

比赛演示的唯一剧本。投影 1920×1080，Chrome 全屏（F11），`--mute` 不要开。
目标：评委在 5 分钟内看到「家 → 川 → 淮扬」三种截然不同的手感，以及「地图后面还有很多」。

## 开演前（30 分钟清单）

- [ ] `npm run build` → 拷 `dist/` 到 U 盘（见 `docs/WORKFLOW.md` §6），现场断网也能跑
- [ ] 投影分辨率确认 1920×1080，浏览器缩放 100%
- [ ] 音箱出声：开场前点一下页面解锁音频（浏览器手势限制），试播 `mus_home`
- [ ] 存档重置：URL 加 `?fresh`，或直接用演示专用 URL（下表）
- [ ] 备用视频已拷到桌面双击可播（见 §录制备份视频）

## 时间轴（总 5:00）

| 时间 | 台词要点 | 操作 | 兜底 |
| --- | --- | --- | --- |
| 0:00–0:30 | 「滋啦厨房——把中国菜系做成一个一个的厨房。」 | 打开家庭厨房，随手抓一个番茄抛接 | 抛接失败也是卖点（玩具物理） |
| 0:30–1:30 | 「教学关：慢、宽容。磕蛋→搅拌→翻面→叠放。」 | 完整做煎饼塔前 3 步，动作放慢，让印章/拟声字出现 | 某步做砸→展示「oops 也有奖励，不卡关」 |
| 1:30–2:00 | 「攒的钱买这台猛火灶——它是去四川的钥匙。」 | 商店买 `wok_burner`，撕胶带拆箱 | 金币不够就 `?coins=999` 重进 |
| 2:00–3:15 | 「川：节奏厨房。颠锅要踩节拍，爆火会震屏。」 | 宫保鸡丁：颠锅（踩点）→撒花椒→爆火→扣饭 | kung_pao 未合并→蛋炒饭热身；讲到节拍即可 |
| 3:15–4:00 | 「买了专业刀具，扬州见——刀工厨房，慢、静。」 | 进淮扬，站 1 俯视微距，沿引导线切 2–3 刀，慢动作特写 | slice_lines 未合并→展示布景+彩蛋（戳豆腐、锦鲤） |
| 4:00–4:45 | 「美食地图：11 个厨房，今天能玩 3 个。」 | 打开地图，指 11 个图钉、3 条支线、迷雾里的明信片 | 地图未合并→念设计文档的厨房清单 |
| 4:45–5:00 | 「每个新厨房只是一份数据文件。谢谢！」 | 回家庭厨房自由玩 5 秒收尾 | — |

## 节奏红线

- 任何一步卡住 >10 秒：跳下一节，别修。演示是tour，不是 debug。
- 全程嘴上不停：念事件的名字（「听见了吗？snap」），评委吃这套。
- 彩蛋至少触发 1 个（家庭厨房小黄鸭 / 川麻将「胡了!」/ 淮扬锦鲤）。

## 录制备份视频（E7 验收的一部分）

Windows 自带 Xbox Game Bar（Win+G），无需装 OBS：

1. Win+G → 捕获 → 设置 30/60fps，录「窗口」模式。
2. 按上面的时间轴完整走一遍（可以剪，但按真实速度）。
3. 导出 mp4 → 拷到 U 盘 + 答辩电脑桌面，文件名 `sizzle-backup.mp4`。
4. 播放检查：音效听得见、字幕（拟声字）看得清。
